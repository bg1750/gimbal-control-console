Pan-Tilt Gimbal Control Console

A desktop operator console for a two axis camera platform. Python and PyQt6.

Some of my professional work can't be shown publicly, so I built this as a stand-in. It uses the same design patterns and interface techniques I developed on the job, applied to a neutral example and wired to a software simulator instead of real hardware.

What it does

  • A hand drawn artificial horizon and heading compass that track the platform's live attitude.
  • Pan, tilt, and zoom controls, plus a slew rate "gear" that scales how fast the axes move.
  • Connection monitoring for five subsystems, with status lights that blink when one drops offline.
  • A latching emergency stop that freezes all motion and flashes until you reset it.
  • A built-in simulator, so the whole thing runs with no hardware attached.

Run it

This is a desktop app, so it runs locally rather than in the browser:

pip install -r requirements.txt
python gimbal_console.py
