# Changelog

## v1.0
- Initial release.
- Two-axis attitude instrument (artificial horizon) with live pitch/roll.
- Pan heading compass.
- Slew-rate, pan, tilt-angle, and zoom-stage controls.
- Per-subsystem connection-status monitoring with blink-on-fault indicators.
- Latching emergency stop with flashing status banner.
- Built-in simulator so the console runs with no hardware attached.
